## Install (easiest → TrollStore)

### Requirements
- iPhone / iPad on a TrollStore-supported iOS version  
- Or a PC + [Sideloadly](https://sideloadly.io/) if you don’t have TrollStore

### Steps (TrollStore)
1. Download `CrossyRoad_Hacked_By_Buns.ipa` from **Releases**
2. AirDrop / Files it onto your iPhone
3. Open the IPA in **TrollStore** → **Install**
4. If you already have an older “CROSSY HACKED BY BUNS”, **delete it first**
5. Open the new app → tap **OK** on the Buns popup (Subscribe is optional)

### Steps (Sideloadly — no TrollStore)
1. Install [Sideloadly](https://sideloadly.io/) on your PC
2. Plug in your iPhone, trust the computer
3. Drag `CrossyRoad_Hacked_By_Buns.ipa` into Sideloadly
4. Sign with your Apple ID and install  
5. On iPhone: **Settings → General → VPN & Device Management** → trust the certificate  
6. Note: free Apple IDs usually need a **re-sign every ~7 days**
