# Install guide — CROSSY ROAD HACKED BY BUNS

This is a **custom IPA** (not the App Store game). Install it with **TrollStore** or **Sideloadly**.

## 1) Download the IPA

1. Open: https://github.com/FaZeBuns/CrossyRoad-Hacked-By-Buns/releases/latest  
2. Download **`CrossyRoad_Hacked_By_Buns.ipa`** (~124 MB)  
3. Wait for the full download (don’t open a half-finished file)

---

## 2A) Install with TrollStore (recommended)

TrollStore keeps the app installed permanently (no 7-day refresh).

1. Put the IPA on your iPhone (AirDrop, Files, Safari download, etc.)
2. Open **TrollStore**
3. Tap the IPA → **Install**
4. If install fails because an old build exists: delete **CROSSY HACKED BY BUNS**, then install again
5. Launch the app from your Home Screen
6. You’ll see the **HACKED BY BUNS** popup once:
   - **Subscribe** → opens YouTube (popup stays open)
   - **OK** → closes the popup
7. Find the **🐰 bunny button** on the left edge of the screen — drag it anywhere you like, tap it to open the hack menu

Done.

---

## 2B) Install with Sideloadly (no TrollStore)

1. On a Windows/Mac PC, install [Sideloadly](https://sideloadly.io/)
2. Connect your iPhone with a cable and unlock it
3. Open Sideloadly → drag in `CrossyRoad_Hacked_By_Buns.ipa`
4. Enter your Apple ID → Start
5. On iPhone go to:  
   **Settings → General → VPN & Device Management** → trust the developer profile
6. Open the app

**Reminder:** with a free Apple ID, Sideloadly apps usually expire in about **7 days**. Re-sign with Sideloadly again when it won’t open.

## Troubleshooting

| Problem | Fix |
|--------|-----|
| App won’t install | Delete old “CROSSY HACKED BY BUNS”, free some storage (~500 MB+), try again |
| Black screen / crash on open | Force-quit, reopen once. If still broken, delete app + reinstall IPA |
| Popup says Subscribe / OK | That’s the custom Buns popup — tap OK to continue |
| Can’t find the hack button | It’s the 🐰 bunny at the left edge — drag it onto the screen if hidden |
